Pertidaksamaan Rasional

Pengertian, konsep dasar, langkah penyelesaian, dan lima contoh soal bertahap.

1. Pengertian Pertidaksamaan Rasional

Pertidaksamaan rasional adalah pertidaksamaan yang memuat bentuk pecahan aljabar, yaitu pecahan yang pembilang dan/atau penyebutnya berupa bentuk aljabar.

f(x) / g(x) > 0

Keterangan: f(x) adalah pembilang, g(x) adalah penyebut, dan g(x) ≠ 0 karena penyebut tidak boleh bernilai nol.

Tanda yang dapat digunakan adalah >, <, ≥, dan ≤.

2. Konsep Penting

A. Titik kritis

Titik kritis adalah nilai x yang membuat pembilang atau penyebut bernilai nol. Nilai pembilang dapat dimasukkan jika tanda pertidaksamaan mengizinkan. Nilai yang membuat penyebut nol selalu dikecualikan.

(x − 2)/(x + 1) ≥ 0

Pembilang: x − 2 = 0 → x = 2. Penyebut: x + 1 = 0 → x = −1. Titik kritisnya adalah −1 dan 2.

B. Garis bilangan dan uji tanda

Titik kritis membagi garis bilangan menjadi beberapa interval. Pilih satu angka uji dari setiap interval, lalu tentukan tanda pecahannya.

3. Langkah-Langkah Penyelesaian

  1. Pindahkan semua suku ke satu ruas sehingga bentuknya dibandingkan dengan nol.
  2. Faktorkan pembilang dan penyebut jika memungkinkan.
  3. Cari titik kritis dengan membuat pembilang dan penyebut sama dengan nol.
  4. Buat garis bilangan, bagi menjadi interval, lalu lakukan uji tanda.
  5. Pilih interval yang sesuai dengan tanda pertidaksamaan dan tuliskan himpunan penyelesaiannya.

4. Contoh Soal dan Penyelesaian

Contoh 1 — Dasar

Soal

(x − 2)/(x + 1) ≥ 0

Penyelesaian

  1. Titik kritis: x = 2 dari pembilang dan x = −1 dari penyebut.
  2. Interval: (−∞, −1), (−1, 2), dan (2, ∞).
  3. Uji tanda: berturut-turut positif, negatif, dan positif.
  4. Ambil interval positif serta x = 2. x = −1 dikecualikan karena penyebut nol.
HP = (−∞, −1) ∪ [2, ∞)
Contoh 2 — Tingkat menengah

Soal

(x² − 4)/(x − 1) < 0

Penyelesaian

  1. Faktorkan: x² − 4 = (x − 2)(x + 2).
  2. Titik kritis: x = −2 dan x = 2 dari pembilang; x = 1 dari penyebut.
  3. Uji tanda pada interval: negatif, positif, negatif, positif.
  4. Ambil interval yang negatif. Semua titik kritis tidak dimasukkan.
HP = (−∞, −2) ∪ (1, 2)
Contoh 3 — Tanda ≤

Soal

(2x + 1)/(x − 3) ≤ 0

Penyelesaian

  1. Pembilang nol saat 2x + 1 = 0, sehingga x = −1/2.
  2. Penyebut nol saat x − 3 = 0, sehingga x = 3.
  3. Uji tanda: x < −1/2 positif; −1/2 < x < 3 negatif; x > 3 positif.
  4. Ambil interval negatif dan x = −1/2. x = 3 tidak boleh dimasukkan.
HP = [−1/2, 3)
Contoh 4 — Pembilang kuadrat

Soal

(x² − 9)/(x + 2) ≥ 0

Penyelesaian

  1. Faktorkan: x² − 9 = (x − 3)(x + 3).
  2. Titik kritis: x = −3 dan x = 3 dari pembilang; x = −2 dari penyebut.
  3. Uji tanda: x < −3 negatif; −3 < x < −2 positif; −2 < x < 3 negatif; x > 3 positif.
  4. Ambil interval positif serta x = −3 dan x = 3. x = −2 dikecualikan.
HP = [−3, −2) ∪ [3, ∞)
Contoh 5 — Faktor sama

Soal

(x² − x − 6)/(x² − 4) > 0

Penyelesaian

  1. Faktorkan: [(x − 3)(x + 2)]/[(x − 2)(x + 2)] > 0.
  2. Syarat penyebut awal: x ≠ −2 dan x ≠ 2.
  3. Faktor (x + 2) dapat dicoret untuk uji tanda, tetapi x = −2 tetap dikecualikan.
  4. Bentuk sederhana (x − 3)/(x − 2) positif saat x < 2 atau x > 3. Keluarkan x = −2 dari interval x < 2.
HP = (−∞, −2) ∪ (−2, 2) ∪ (3, ∞)

5. Kesalahan yang Perlu Dihindari

  • Penyebut tidak boleh bernilai nol.
  • Titik pembilang hanya dimasukkan jika tanda pertidaksamaan menggunakan ≥ atau ≤.
  • Titik penyebut tidak pernah dimasukkan, meskipun faktor yang sama dicoret saat penyederhanaan.
  • Jangan mengalikan silang tanpa mengetahui tanda penyebut karena arah pertidaksamaan dapat berubah.

6. Ringkasan

Inti penyelesaian pertidaksamaan rasional adalah mencari titik kritis dari pembilang dan penyebut, membagi garis bilangan menjadi interval dan menentukan tandanya, lalu memilih interval sesuai tanda pertidaksamaan dengan tetap mengecualikan nilai yang membuat penyebut nol.
